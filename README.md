# Alcolocator

An interactive vehicle-safety concept exploring alcohol detection, driver assessment, alerts, and intelligent vehicle safety.

## Overview

Alcolocator is a web-based prototype designed to demonstrate how an intelligent in-vehicle safety system could work.

The project combines an interactive interface, simulations, driver-assessment features, product visualizations, and a conceptual safety dashboard into one platform.

## Features

* Interactive system workflow
* BAC simulation
* Fit-to-drive assessment
* Interactive safety dashboard
* Product visualization
* Before/after comparison
* Drive Home interactive experience
* ALCO Assistant
* FAQ and project roadmap
* Responsive futuristic interface

## Live Demo

https://alcolocator-v1.netlify.app/

## Project Status

Alcolocator is currently a prototype and concept project.

The current web experience demonstrates the proposed interface and system behavior. Dashboard readings are simulated and are not connected to physical sensors.
